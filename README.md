# MMDU Secure Exam — downloads

The locked exam window for MMDU online exams (onlinelms.mmumullana.org). Download the latest version from
[Releases](../../releases/latest).

- **Windows 10/11:** `MMDUSecureExam-Setup-<version>.exe` (installs for your user, no admin needed) or
  `MMDUSecureExam-Portable-<version>.exe` (runs without installing).
  Windows may show "Windows protected your PC": click **More info → Run anyway**.
- **macOS:** `MMDUSecureExam-<version>-arm64.dmg` (Apple Silicon) or `-x64.dmg` (Intel).
  The first time, right-click the app → **Open** → **Open**.

To take an exam: open your exam on onlinelms.mmumullana.org and click **Open in MMDU Secure Exam**,
or start the app and click **Open MMDU exams**.
